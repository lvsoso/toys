# 项目规则

## 范围
- 独立 Chrome Manifest V3 插件，不修改参考插件。
- 只处理当前 Udemy 正式课时：下载原字幕、导入 SRT/VTT、播放显示、本地复用。
- 支持主动将当前课时字幕交给本机 Flask 后端，以 Codex CLI 的 gpt-6-luna / low 分批翻译为简体中文。字幕会发送至 Codex 当前配置的模型服务。
- 保留手动下载/导入；不做音频识别、整课批量下载或并发模型请求。

## 结构与约定
- 根目录放 manifest、页面及运行脚本；`tests/` 放 Node 内置测试。
- `subtitles.js` 负责格式解析/导出与课时标识，`bridge.js` 只观察页面 GraphQL 字幕元数据。
- `content.js` 负责 Udemy 获取、课时缓存及字幕浮层（隐藏的原生轨道负责时间同步）；`popup.*` 负责用户操作。
- `background.js` 只代理固定 localhost 后端接口；`backend/` 放 Flask API、串行任务与 Codex 调用。`backend/data/` 保存任务和译文，不提交。
- 后端只绑定 127.0.0.1，校验 Host、扩展来源和客户端标识。不得向任意网络地址代理请求。
- 任务由后端执行，关闭弹窗不取消；状态为 queued/running/completed/failed，失败和重启中断只由用户主动重试。
- 缓存包括原文/时间轴、源目标语言、模型服务身份、模型、推理强度和提示词版本。每批校验完整 ID 后原子保存；缓存命中不调用模型。
- 原时间轴由程序保存，模型只能返回 ID 和译文；前批结果可先显示，全部完成后保存为本课字幕。手动导入解除自动加载任务关联。
- 字幕显示设置全局保存在 `subtitle_style`，包含 `font_size`（18–48px，默认24）与 `position`（距视频顶部10–100%，默认85）。修改立即生效并跨课时/标签页复用，恢复默认不删除字幕缓存。
- `content.css` 仅控制本插件浮层及原生 cue；浮层使用统一背景、随文字收缩的宽度（最大为视频宽度的92%）和百分比纵向位置。通过隐藏 TextTrack 的 cuechange 同步时间，纯文本插入 DOM；仅显示时合并连续同语言行（英文空格连接、中文直接连接），中英混排或不能识别的行保留换行，不改变缓存和时间轴。容器全屏移动浮层；video 元素单独全屏或画中画使用原生字幕。不改官方字幕，不触发翻译。
- Codex 采用独立工作目录、只读沙箱、关闭工具及 MCP，复用既有模型服务认证，不改全局 Codex 配置。
- 原生 JavaScript，无构建、第三方运行依赖；自定义变量/函数用 snake_case，函数写简短 JSDoc。
- Udemy 数据、消息、文件均视为外部输入；禁止执行字幕 HTML、记录字幕正文/签名 URL/登录信息。
- 存储键使用站点 + 课程路径标识 + 课时 ID；导入只替换明确选定课时的缓存。
- 异步操作返回后复核课时，禁止把旧请求结果显示到新课时。

## 验证与变更
- 改动必须对应已确认范围；公共接口或范围调整先确认。
- 新的长期文件、命令及行为同步更新 README.md。
- 运行 `node --test tests/*.test.cjs` 和 JavaScript 语法检查。
- 运行 `python -m unittest discover -s tests -p 'test_*.py'`；使用可控假翻译器验证状态机/缓存/重试，并另行报告真实 Codex 验证。
- 实际 Udemy 联调与本地模拟测试分开报告；本地测试不代表线上兼容性已验证。
